### 🤖 The GenAI Testing Portfolio
*A suite of 5 specialized micro-projects demonstrating production-grade testing for Large Language Models and AI Agents.*

* **What it is:** An automated prompt-injection matrix testing an AI's persona stability.
* **Tech:** Promptfoo, LLM-as-a-Judge.
* **Impact:** Prevents emotional jailbreaks and system prompt leaks in production chatbots.

#### 2. [RAG Truth Engine](https://github.com/Shaik-Subhan-Vali/GenAI_Projects/tree/main/RAGTruthEngine)
* **What it is:** A mathematical hallucination detector for corporate Vector Databases.
* **Tech:** Python, Pytest, Custom API Retry-Logic.
* **Impact:** Intercepts fabricated data (e.g., incorrect historical records) before reaching the user.

#### 3. [Agent Security (Confused Deputy)](https://github.com/Shaik-Subhan-Vali/GenAI_Projects/tree/main/AgentSecuritySuite)
* **What it is:** A backend security test verifying an AI Agent's resistance to malicious tool-use.
* **Tech:** Promptfoo, Groq (Llama 3.1).
* **Impact:** Ensures users cannot bypass system guardrails to trigger unauthorized APIs (e.g., forced refunds).

#### 4. [AI Performance Gate](https://github.com/Shaik-Subhan-Vali/GenAI_Projects/tree/main/PerformanceGate)
* **What it is:** A CI/CD pipeline script enforcing non-functional LLM SLAs.
* **Tech:** Python, Groq API, GitHub Actions.
* **Impact:** Automatically blocks code merges if prompt modifications exceed strict Latency (TTFT) or Token Budget limits.

#### 5. [Agentic UI Orchestration Test](https://github.com/Shaik-Subhan-Vali/GenAI_Projects/tree/main/AgenticUITest)
* **What it is:** An End-to-End browser test intercepting non-deterministic, streaming AI Server-Sent Events (SSE).
* **Tech:** Playwright, TypeScript, Node.js.
* **Impact:** Dynamically validates the AI's conversational state-machine and ReAct loop inside the actual DOM.
